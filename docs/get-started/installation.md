# Installation and upgrade

## Install

1. Go to [Github Release Page](https://github.com/arcane-forge-ai/arcane-forge-studio/releases) and download the newest version.
2. Unzip the zip file into your desired installation directory.
3. Click `arcane_forge.exe` to run the software.

## Upgrade

Learn how to upgrade your Arcane Forge installation to the latest version.

### Use upgrade script

**Prereq**: Python

1. Double click `update.bat` in your installation folder and follow prompt
2. Check `version.txt` in your installation folder or [check version inside software](../supports/faqs.md#where-can-i-find-my-version) to see if the upgrade is successful.

### Manual

Go to [Github Release Page](https://github.com/arcane-forge-ai/arcane-forge-studio/releases) and [reinstall](#install).
